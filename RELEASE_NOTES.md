# CBMS RCDF LGU Tool — Release Notes

## Version 1.0.0 (September 2026) — Initial Release

### What's New

- **First public release** of the CBMS RCDF LGU Tool
- Standalone Windows desktop application — no XAMPP, PHP, Python, or MySQL required
- One-click RCDF import with automatic decryption and database insertion
- Three analytics modules: Person, Household, Barangay
- Advanced multi-select filtering with real-time pie chart visualizations
- Excel export with automatic code-to-label decoding (546 CBMS variables)
- Statistical tables with cross-tabulation support
- Machine-locked licensing with RSA-2048 cryptographic signatures
- 14-day free trial
- Multi-municipality support
- Auto-logout after 1 hour of inactivity
- Audit logging for all sensitive actions
- Custom logo upload
- Bundled Python 3.12 runtime for RCDF decryption (no system Python needed)

### Download

- **CBMS-1.0.0-setup.exe** (~918 MB) — Windows NSIS installer (64-bit)

### Installation

1. Download `CBMS-1.0.0-setup.exe`
2. Double-click to run the installer
3. Follow the installation wizard
4. Launch CBMS from the desktop shortcut
5. Log in with the default credentials (see README)
6. Start a free trial or activate a license
7. Import your RCDF data via Admin → Data Management

### System Requirements

- Windows 10 64-bit or later
- 4 GB RAM (8 GB recommended)
- 2 GB free disk space

### Known Issues

- First launch may take 10–20 seconds while the database initializes
- Windows Defender may flag the installer — add an exclusion if needed
- The app must be closed before reinstalling or updating
